# Contributing

Contributions should improve technical accuracy, accessibility, source traceability, or reading experience.

## Report a content correction

Include:

1. Chapter and page number.
2. The current claim or label.
3. The proposed correction.
4. An exact source link at the locked commit.
5. The date you verified it.

## Report source drift

If current DeepSeek Harness behavior differs from this source-locked handbook, identify both the locked source and the newer upstream commit. Source drift should become a new handbook version; it should not silently change the historical edition.

## Visual and accessibility reports

Please report unreadable text, broken arrows, clipped labels, duplicated pages, missing pages, low contrast, or inaccurate alt text with a screenshot and page number.

## Pull requests

Keep changes scoped. Do not add third-party characters, logos, or branded visual assets. Any replacement artwork must be original or carry a compatible license with clear attribution.
