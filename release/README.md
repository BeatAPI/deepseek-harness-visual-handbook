# Release Artifacts

Keep the Git repository lightweight by committing only the WebP reading assets.

For each tagged GitHub Release, attach:

- `DeepSeek-Harness-Visual-Handbook-vX.Y.Z.pdf` — the complete PDF.
- `DeepSeek-Harness-Visual-Handbook-vX.Y.Z-PNG.zip` — optional original-resolution PNG archive.
- `SHA256SUMS.txt` — checksums for both downloads.

Do not commit the PDF or PNG archive into Git history. Link the latest release from the root README after the public repository exists.
